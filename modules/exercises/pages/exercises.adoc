:navtitle: Exercises

These hands-on labs reinforce the concepts covered in the modules.
Each exercise builds a small but complete program that you run on the lab bastion against a local Kubernetes cluster.

All exercises run on the *bastion virtual machine* provided with the lab.
You install the toolchain (Go, `kubectl`, Kind) and spin up a single-node Kubernetes cluster with Kind once, in xref:setup.adoc[Setup], then work through the exercises in order.
Before you start, follow xref:LABENV:index.adoc[Lab Environment] to request the RHEL VM and log in.

* xref:setup.adoc[] -- Install the toolchain and create your Kind cluster
* xref:1-1-build-a-controller-using-client-go-from-scratch.adoc[] -- Wire up the client-go pipeline from scratch
* xref:1-2-implement-optimistic-locking-and-leader-election-via-lease.adoc[] -- Add leader election to your controller
* xref:2-develop-a-custom-validating-webhook-for-container-registry-enforcement.adoc[] -- Build and deploy a validating admission webhook
