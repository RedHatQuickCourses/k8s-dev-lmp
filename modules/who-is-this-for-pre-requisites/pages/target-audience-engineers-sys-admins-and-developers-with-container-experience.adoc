#  Target audience: Engineers, sys admins, and developers with container experience

= Prerequisites and Target Audience

Before embarking on this learning path, it is essential to ensure that you have the foundational knowledge required to digest the architectural complexities of the Kubernetes control plane. This curriculum is designed for technical practitioners who are ready to move beyond basic container management and transition into platform engineering and cluster-level development.

== Who is this for?

This learning path is specifically tailored for:

*   **Platform Engineers:** Professionals tasked with building internal developer platforms, managing multi-cluster environments, and extending Kubernetes functionality.
*   **Software Engineers:** Developers who need to understand how to interact programmatically with the Kubernetes API, develop custom operators, or build controller-based automation.
*   **System Administrators:** Sysadmins looking to deepen their expertise in cluster internals, security hardening, and advanced networking patterns to support robust production environments.

== Recommended Prerequisites

While this path is comprehensive, it assumes you are not a beginner to the ecosystem. To succeed, you should be comfortable with:

*   **Container Fundamentals:** A solid understanding of container runtimes (e.g., CRI-O, containerd), images, and basic container lifecycles.
*   **Kubernetes Basics:** Competency in deploying and managing standard workloads (Pods, Deployments, Services, ConfigMaps).
*   **Distributed Systems Knowledge:** An awareness of fundamental concepts such as consistency, consensus, replication, and network partitions.
*   **Go Programming (Recommended):** Since much of the Kubernetes ecosystem—including `client-go` and `controller-runtime`—is written in Go, familiarity with the language will significantly lower the barrier to entry for the hands-on exercises.

== Ideal Baseline

To gauge your readiness, we recommend the following as an ideal entry point:

1.  **Certification level:** Proficiency equivalent to the *Certified Kubernetes Application Developer (CKAD)*.
2.  **Red Hat Training Tracks:** Successful completion of the *DO-180 (Introduction to Containers, Kubernetes, and Red Hat OpenShift)* and *DO-280 (Red Hat OpenShift Administration: Core)* tracks provides the most relevant background for the advanced topics covered in this course.

=== Self-Assessment Checklist
If you can answer "Yes" to the following questions, you are prepared to begin Week 0:

*   [ ] Can I explain the difference between imperative and declarative state management?
*   [ ] Do I understand the basic request flow from `kubectl` to the Kubelet?
*   [ ] Am I comfortable reading YAML-based resource manifests?
*   [ ] Do I have a development environment ready, including a local Kubernetes cluster (e.g., Kind or Minikube)?
