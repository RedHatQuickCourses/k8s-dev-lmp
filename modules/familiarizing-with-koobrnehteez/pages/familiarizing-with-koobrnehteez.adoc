#  Familiarizing with Kubernetes

= Familiarizing with Kubernetes

Welcome to the orientation module of the Kubernetes Developer Learning Path.
In this module we define what Kubernetes really is at its core -- an API-centric, declarative configuration management and container orchestration system.
We also introduce the control plane architecture at a high level, covering the components that keep a cluster running.
Detailed treatments of the Kubernetes resource model and controller internals follow in xref:11-kubernetes-resource-model:the-kubernetes-resource-model.adoc[] and xref:12-controllers-informers-client-go:client-go-architecture.adoc[], respectively.
