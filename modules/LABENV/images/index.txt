To complete the hands-on exercises in this learning path, you will need access to a running OpenShift cluster. You can request a self-service demo cluster directly from the Red Hat Demo Platform.

To request your demo cluster, begin by opening the Red Hat OpenShift Container Platform Cluster catalog item. You can find the link to this catalog in the course resources. Once you have opened the page, click the "Order" button to access the order form.

From here, you will need to complete several required fields. First, under "Activity," select the option that best matches your context, such as "Practice" or "Enablement." Next, choose the appropriate "Purpose" from the provided dropdown menu. For "Salesforce IDs," provide an Opportunity, Campaign, or Project ID if your activity requires it; otherwise, simply acknowledge that you will supply the information within 48 hours. 

For the technical specifications, AWS is the preferred cloud provider, but any available provider is acceptable. You may choose any version of OpenShift, select a cluster size that suits your specific needs, and configure the user creation settings as required. Once you have filled out these fields, submit your order and wait for the cluster to be provisioned.

After your cluster is ready, you can access it via the dashboard, which provides a KUBECONFIG file for your environment. Download this file and link it into your local path so that your command-line tools—specifically oc or kubectl—use it by default. You can do this by running the command: export KUBECONFIG, followed by the path to your downloaded kubeconfig file.

Once you have configured your environment, you are ready to begin the hands-on exercises.
