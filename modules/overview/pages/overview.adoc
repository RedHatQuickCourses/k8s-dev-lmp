= Course Overview
:navtitle: Overview

This course provides a comprehensive overview of the Kubernetes architecture and its powerful extensibility mechanisms.
We will start by learning how the Kubernetes API functions behind the scenes, exploring how cluster requests are authenticated, authorized, and validated by the control plane.
The core of the course focuses on platform automation, teaching you how to extend Kubernetes by defining custom resources and writing custom controllers or operators to automatically manage different workloads.
