If you are looking to dive deeper into the topics covered in this course, we have compiled a list of recommended resources. While these are not required reading, they serve as excellent references to complement our training modules.

First, for those interested in Kubernetes Security and Observability, I recommend the book of the same name by Brendan Creane and Amit Gupta, published by O'Reilly. This is a practical guide for implementing robust security and effective monitoring. It provides a detailed look at network policies, role-based access control, runtime security, and observability patterns. It is an ideal companion to the course module on cluster hardening, where you will study networking, authentication, and authorization in greater depth.

Second, for a deeper understanding of architecture, look into Designing Distributed Systems by Brendan Burns. This book explores common patterns—such as sidecars, ambassadors, and adapters—and demonstrates how they are implemented within Kubernetes. It provides a solid conceptual foundation for the distributed challenges we cover later in this course, specifically regarding topics like idempotency, leader election, and controller sharding.
