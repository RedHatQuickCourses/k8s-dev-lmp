These hands-on labs are designed to reinforce the concepts we have covered throughout this course. By working through each exercise, you will build a small but complete program that you can run directly against a Kubernetes cluster.

Before we begin, please note that all exercises require access to a running OpenShift cluster. If you do not have one set up yet, please consult the Lab Environment documentation to request a demo cluster and configure your KUBECONFIG file.

We have three primary exercises to work through:

First, we will build a controller using client-go from scratch, where you will wire up the client-go pipeline.

Second, we will implement optimistic locking and leader election via Lease to add resilience to your controller.

And finally, we will develop a custom validating webhook to enforce container registry policies, which you will then build and deploy.
