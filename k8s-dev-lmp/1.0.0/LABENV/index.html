Lab Environment

The hands-on exercises in this learning path run on a bastion virtual machine running Red Hat Enterprise Linux (RHEL). You do everything — editing files, installing tools, building code, and running kubectl — while logged in to this VM, so you do not need to install anything on your own laptop.

The VM starts as a plain RHEL host. In Setup you install the toolchain (Go, kubectl, and Kind) and create a single-node Kubernetes cluster with Kind that runs on the VM itself. There is no separate cluster to provision.

Requesting the RHEL VM

Order a RHEL VM from the Red Hat Demo Platform catalog:

  1. Open the RHEL VM sandbox catalog item.

  2. Click Order, accept the defaults, and submit the request.

  3. Wait for the provisioning email (or the Services page in the catalog) to report the VM is ready. This usually takes a few minutes.

When provisioning completes, the catalog shows the connection details for your VM, including an SSH command similar to the one below.

Logging In to the Bastion

Copy the SSH command from your provisioning details and run it from your local terminal. It looks similar to this (your host name and credentials will differ):

$ ssh lab-user@rhel.example.opentlc.com
The catalog details page shows the exact host name and the password (or key) to use. Use the values from your provisioning details, not the example above.

Once connected, your shell prompt looks similar to this:

[lab-user@rhel ~]$

The lab-user account has passwordless sudo, which you use in Setup to install packages.

You are now ready to continue with Setup, where you install the toolchain and create your Kubernetes cluster.
